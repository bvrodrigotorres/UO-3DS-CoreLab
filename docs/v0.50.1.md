# CoreLab v0.50.1 — Memoria de equipo, pausa y objetivo manual

La foto corresponde a `syncArbitrateAddress`, llamado por `gspEventThreadMain` en
el ejecutable 0.50. La dirección no identifica por sí sola el punto que inició el
fallo. Se reducen los picos de RAM que pueden terminar el proceso mientras ese
hilo todavía está activo; se requiere confirmación de estabilidad en la consola.

## Cambios

- La caché CPU de capas de personaje baja de 4 MiB a un máximo estricto de
  1.536 KiB, suficiente para la capa de caballo original de 1.238.696 bytes.
  Las capas mayores se rechazan antes de reservar el archivo completo.
- Antes de componer un atlas de personaje (hasta 4 MiB montado), se comprueba la
  memoria normal disponible, se libera la caché si es necesario y se conservan
  512 KiB de margen. Si no alcanza, falla la preparación sin aplicar el equipo.
  También se comprueba la admisión de cada archivo de capas.
- La pausa sigue bombeando render, lecturas y reintentos durante toda su duración;
  no se detiene después de dos cuadros limpios. Teletransportar reinicia además
  la preparación. NPC, combate, puertas y temporizadores siguen congelados.
- Un objetivo elegido mediante selección manual tiene prioridad sobre defensa
  automática mientras esté vivo y dentro de alcance/altura. Cambiar de objetivo
  durante la defensa puede seleccionar también una criatura todavía neutral.
  Cuando el objetivo deja de ser válido se retoma la defensa automática. La
  selección automática sigue priorizando al primer agresor cuando no hay una
  elección manual válida.

## Validación

Suite ASAN/UBSAN, regresión de selección mientras ataca otro enemigo, rechazo de
una capa excesiva y liberación de caché. Sonda con el mapa real 768 completo,
minimapa, grupos de techos y 3 MiB reservados para otros residentes: 24 ciclos de
preview/aplicación/composición de montura, con pico 30.171.629 de 31.457.280 bytes
(límite 30 MiB). Se compilan ARM y CIA y se conservan sus símbolos para el próximo
informe. Estas pruebas no reproducen el hardware de la Old 3DS.

## Instalación y comprobación física

Refrescar Universal-Updater y elegir **Actualizar juego HOME (CIA)**, unos 1 MB.
No reinstalar el mapa. Abrir CoreLab 0.50.1 y Continuar. Se conserva el título
000400000D0C4C00 y se incrementa la versión interna a 7.0.1.

Probar caminar por varias zonas, aplicar conjuntos montado y a pie, teletransportar
y esperar sin quitar pausa, y usar X para cambiar de objetivo mientras otro
ataca. Se conserva todo el contenido del mapa completo 0.50 y las vendas.
