# CoreLab v0.46 — aplicación HOME y archivo de texturas

- CIA nativa: contiene el ejecutable; instala un nuevo icono conservando los
  recursos/partidas de SD. La revisión HOME directa usa otro Title ID y el nombre
  `CoreLab 0.46` para evitar el destino homebrew que pudo quedar asociado al
  icono anterior. No usa el salto de Luma a un 3DSX. Al cerrar
  vuelve a HOME. Las futuras actualizaciones HOME instalan la CIA actualizada.
- Las 7.298 páginas de texturas de exploración se sirven desde un archivo con
  índice validado, offsets y checksum por página. El hilo de lectura conserva
  abierto un solo archivo, con una caché fija de 64 KiB que aprovecha páginas
  contiguas. No se abre un archivo SD por cada textura.
- La prioridad sigue siendo lo cercano y después lo lejano. Se pueden enviar
  hasta cuatro páginas pequeñas preparadas por cuadro dentro de una ventana
  de dos milisegundos y un límite de bytes, sin esperar lecturas en el hilo de
  dibujo. Una transferencia individual puede rebasar la ventana; esta limita
  la admisión, no garantiza una duración máxima en hardware.
- Se conservan cuatro lecturas/4 MiB, 10 MiB de texturas del mapa y reserva de
  memoria lineal. No se carga todo el mapa en RAM. Las texturas antiguas sueltas
  siguen siendo compatibles si todavía no se instaló el paquete rápido.

Instalación: instalar CIA con FBI; instalar una vez `Texturas rapidas de
Britannia` desde la tienda local (aproximadamente 59 MiB comprimidos). No hay
que reinstalar geometría, NPC ni partidas. Entrar a la exploración como antes.
El paquete completo mundial nuevo incluye directamente el formato agrupado.

La agrupación conserva cada T3X e ID de imagen exactamente, sin degradar el
arte. Corrige las aperturas de archivos y amplía el envío de páginas pequeñas;
no afirma igualar todavía todos los tiempos de la campaña normal ni añade
población global. Debe medirse recorriendo el mapa en Old 3DS.
